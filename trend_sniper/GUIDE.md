# 🎯 TrendSniper - GUIDE.md

## 1. Что это за инструмент?
**TrendSniper** — это твой личный скаут в мире open-source и AI. Он ежедневно сканирует GitHub Trending, Hacker News и Product Hunt, чтобы найти проекты, которые можно упаковать в «продукт в папке» и продать.

## 2. Какую боль решает?
- **Паралич анализа:** Тебе не нужно самому листать сотни репозиториев. Движок выдает топ-15 самых хайповых штук за сегодня.
- **Отсутствие идей:** Для каждого найденного проекта движок предлагает сценарий монетизации (Mini-Franchise).
- **Скорость:** Поиск и первичный анализ занимают меньше 30 секунд.

## 3. Как пользоваться (Quick Start)
1. Установи зависимости: `pip install -r requirements.txt`
2. Запусти: `sh launch.sh` или `start.bat`.
3. Нажми **"Start Daily Hunt"**.
4. Выбери 3 самых перспективных проекта для упаковки.

## 4. Бизнес-модель «Цифровая Фабрика»
1. Запускаешь **TrendSniper** утром.
2. Выбираешь проект (например, новый AI-редактор видео).
3. Используешь **Market Intelligence Pro**, чтобы пробить спрос и конкурентов.
4. Упаковываешь по стандарту **Dmitry Standard**.
5. Заливаешь Reels и ведешь трафик в Telegram-хаб.
